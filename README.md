Mail-Guard AI: Context-Aware Phishing and Social-Engineering Detection System

 	
Problem Statement:

Fraudulent emails and messages frequently imitate legitimate organizations or individuals and use
urgency, impersonation, and deceptive requests to obtain sensitive information. Develop an NLP-
based detection system that analyzes email and message content to identify suspicious language,
unusual requests, impersonation indicators, and social engineering tactics. The system should
classify messages according to their potential risk, highlight suspicious phrases, and provide
explanations for its predictions. Appropriate techniques may include text classification, Named
Entity Recognition, intent detection, contextual embeddings, explainable AI, and robustness testing
against variations in message wording.

Features:

* Email spam and ham classification
* Deep learning using a Bi-LSTM model
* Text preprocessing and tokenization
* Model performance evaluation
* Interactive user interface

Technologies Used

* Python
* TensorFlow / Keras
* Pandas
* NumPy
* Scikit-learn
* Gradio

Dataset

The project uses an email dataset containing messages labeled as spam or ham.

Model Performance

The Bi-LSTM model achieved approximately 96.32% test accuracy in the project evaluation.

How to Run

1. Download or clone the project.
2. Install the required dependencies.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Run the notebook cells in order.
